# VPN
中国ではGreat Fire Wallという規制がかけられているため、Wifiを使ってGoogleやChatGPTにアクセスすることができない。

## ブロックチェック
使用したいサイトがブロックされているかどうかは

<https://blocky.greatfire.org/>

などで確認できる

## VPN
規制の状況は刻々と変わるからどれが良いと一概に言うのは難しい。

[China Unicom](./china-unicom.md)を契約しておけば
google等へのアクセスは可能なため、中国本土で契約を見直すことは可能。

### かべネコ
<https://kabeneko.biz/>

安い。クレジットの登録不要で2週間程度使用できるため、とりあえず登録しておくと良いかも。
中国でVPNの規制が強化されていることもあってか、安定して接続できないこともある。
夜は通信速度が低下しがち。

### UCSS
<https://undercurrentss.com/jp/>

高価だが高速で信頼度も高いと聞いたことがある。

## 使えるサイト・使えないサイト
VPNを噛ませなくても見れるかどうか
### 使える
- microsoft
- yahoo
- spotify
### 使えない
- google
- twitch
- NHK
- amazon
- ChatGPT
