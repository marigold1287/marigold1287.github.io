# バック・トゥ・レトロ
ドミニック・ローホーのミニマリスト本。

わたしは完全なミニマリストではないが物欲というかもので満足できるタイプの人間ではなくて
部屋を見渡してもものは少ない方、だと思う。

この手の本は就職してから勤務地が変わって引っ越しすることになった前後によく読んでいたが、
わたしの場合はミニマリストになるためと言うよりは自分の行いを正当化する、確認するために
読んでいるという面が強くある。

## 印象に残った内容
### お気に入りを見つけたらもう比較しない
いつも同じブランドにして、新しいブランドが登場しても見ないことにする。
### 自治体の市民農園
なにかを手作りし、その出来栄えを味わうことは、パソコン画面と向き合って過ごす人たちの多くが感じている空虚感を埋めてくれるでしょう

ただ、わたしの家の周りに市民農園が見当たらない。もう少し調べてみるべきだが。

### 一人で考える時間
単純な動作の趣味、編み物や塗り絵、は一人で静かに考える時間をつくることができる。
### 情報元の絞り込み
取り込む情報を限定する。いくつかのフラグを設置し、情報はそこに絞り込み、ほかはシャットアウトする。
### 隣人のために
人間は自分自身のために多くの物を必要とすればするほど、
隣人のためには尽くすことができません。

これは寄付に対するわたしの考えとよくあっているように思う。
