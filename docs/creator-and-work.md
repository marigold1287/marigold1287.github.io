# 作品と作り手を分けて見られない

2026年10月16日

<https://misskey.io/notes/asdhblw22wu9049r>

朝4時くらいに目覚めてこのノートが目に入った。
確かに私もSNSで気に入ったイラストを見つけたりイベントでお迎えしたりすることがよくあるけど、
SNSでの言動とか嗜好みたいなものに引っ張られて作品に対する評価が変わってしまうということがよくある。
創り手と作品を分離できないというか、お迎えすることに創り手に対する応援の気持ちみたいなものも
含まれているのだと思う。

今までよく分かっていなかったが、SNSのアカウントを使い分ける理由が少し分かったような気もする。
創り手の側からすると自分と作品を分離して見てほしいとか、逆に一体としてみてほしいとか、
そういう考え方の違いがあるのかもしれない。

ただ、私の場合は作品を好きになったら他のアカウントも覗いてしまう質だから、結局、
見る側の性格というか、見る側がどう見たいかという話でもあるかもしれない。

私は総体で見るタイプなのだと思う。それに、今の時代、よほど有名な方なら別としても
SNSを見ない限り作品に触れる機会を知ることすら難しいからこの分離は難しくなっているようにも感じる。

現代の作家に限らず、古典にも当てはまる。
例えばわたしの場合、ゴッホと聞いても何か有名な人くらいの認識しかなかったが、
ゴッホ展に行って生い立ちを知ったのをきっかけにファンになったというか、
好きになれたことがある。もちろんこの場合はSNSではなくて歴史の勉強のようになってしまうのだが。
本人の生い立ちだけでなくて、当時の歴史背景みたいなものも知りたくなってしまう、
というか、知らないと本当は理解できたことにならないだろうくらいに思っている。

逆に風景画を見て「これいいな」と思ってポストカードをお迎えして
後から調べてもっと推せるようになることもあるし...まあ、本当に色々あるのだ。

よく絵の前で光と影が...塗り方が...と話している人を見かけるが、
わたしは絵を描かないからそういう鑑賞の仕方はできない。せいぜい近づいた時に「厚みがある！」みたいに
なるくらいで。なんとなく好き、作者の生い立ちを知るともっと好きになるときもある。

そんなところだろうか。

misskeyのnote一つで色々と考えさせてくれる。
この人は普段の発言も配信も3Dグラも含めて好きだ。
