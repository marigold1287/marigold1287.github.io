# Velo&Galerie Cafe du miconos
自転車&ギャラリー、ミコノス島のカフェといった意味。

横須賀中央駅から歩いて10分くらいのところにあるおしゃれな喫茶店。

それほどあちこち喫茶店に行っているわけではないが、今までの中で一番好きな雰囲気だったかもしれない。

価格も手頃で、カウンター席に座って落ち着いた時間を過ごすことができた。

2026年9月19日、3人展『[秋色エフェメラル](akiiro-ephemeral.md)』のために訪問した。

## ミコノスコーヒー ホット
\500。小さなミルクも付いている。
苦味が強めで美味。
