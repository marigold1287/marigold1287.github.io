# 東方プロジェクト
わたしと東方の接点はおそらくニコ動黎明期の
魔理沙は大変なものを盗んでいきましたとかMODとかになるだろう。

あとはゆっくり実況とかで霊夢と魔理沙を見かけるくらいだったのだが、
2025年5月にプロセカで東方とのコラボイベントがあってそこから興味を持ち始める。

ミクというかボカロもそうだが長続きしているものに間違いはないだろうし、
世界観を理解できれば作品としてちゃんと楽しめるのではないかという思いもあった。

と言ってもわたしはゲームをやらないから漫画を読むくらいでしかないのだが。

## 2026-09-16、misskeyに投稿したノート
まあ、上に書いてある内容と大して変わらないが。


>東方はニコニコ黎明期の「魔理沙は…」とか優曇華院とかタイトル分からんけどゆかりんのやべぇ歌とかで知ってはいたのよね。ただ、ゲームとして知ってたというよりはMADとしてしか知らなくてね。もちろん？クッキーとかそっちも見ているわよ。それで、二十年くらい経ってプロセカが東方とコラボしてね、あれ、東方ってもしかして…って思って調べ始めて。その時に紅魔館の女たちとか恋色の境界とか読んだりして、あーこういう世界観なんだというか、作家さんによって好きな解釈をしていいんだっていうのに惹かれたのかな？ボカロに通じるものを感じてね、それから作品として好きになったっていう感じかしらね。ゲームやってないけど…Steamの体験版はやったのよ。あーこれ無理！ってなっちゃった

これを投稿したあとにむじなさんという方が幻想少女大戦というのを勧めてくれた。
