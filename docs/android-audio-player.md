# Androidで使えるMP3プレイヤー
広告がなくて使いやすそうなもの。といってもデザインや使い勝手は好みがあるから
あくまでもわたしの主観

- VLC たぶん一番有名どころ
- Musicolet プレイリスト管理やファイル検索もしやすいが、ReplaygainはPro版でのみ対応。ただ、買い切り1500円くらいだから気に入ったら買えばいいかなという感じ
- Gramophone シンプルでReplaygainも対応。ただ、フォルダごと・アルバムごとプレイリストに登録するというのができない。基本的に1曲ずつしか入れるしか無いと言うのが不便かな
- Booming Music 個人的にはこれが一番良いと思う。リプレイゲインにも対応している（再生画面からイコライザの設定画面へ。一番下にリプレイゲインに関する設定がある）。プレイリスト管理もしやすい。
