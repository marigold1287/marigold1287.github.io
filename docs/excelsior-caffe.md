# エクセルシオールカフェ
[ドトール](./doutor.md)系列のカフェ

## 2026-08-08
小川町の近くの店に入ってみる。
店内は非常に広くてとりあえず水筒を置いて座席を確保してレジに向かう。

会計を済ませたらとりあえず横の受取口で飲み物を受け取る。
食べ物はブザーで呼び出されたら取りに行く。

水は無料。食べ終わったらトレイを下げる。そのまま下膳口においておけば良さそう。

たまたまかもしれないが、トレイがベタベタする。
