# モモ
この時間泥棒というのが何を指しているのかは人それぞれなのかもしれないが、
私には資本主義に感じられる。
あるいはSNSみたいな人の興味関心を金に変える商売の象徴か。

本が書かれたのは1973年、作者のミヒャエル・エンデがローマに住んでいた時のこと。
この本が書かれてから50年経って、当時よりも世界はずっと便利で暮らしやすくなっている。
それなのに人間は何かを求めてあくせくと働き続けている。

その何かとは一体何なのか、それが私にはわからない。今、私は休職している。
おそらく、復職不可能というほど調子が悪いわけでもない。

皆はこの何かがなにか分かっているのか。金。私は幸いにも金銭的な余力があるから
こんなことを語っていられるのか。金のためにあくせく働くしか無い人もいるのだろう。
でも、実際のところはどうなのだ。何を求めて、何のために生きているのか、
それを見失ってもっともっとと求めているのが灰色の男たちなのだろうか。

純粋さ、人のため、人というのはこの人という特定の人ではなくて未来のため。
周りに流されずに自分を貫くこと。正しく生きるために生きるということ。
わたしはそういう生き方をしたい。

2026年10月20日。
