# MP3のタグについて
## ID3v1
mp3の末尾に書き込まれた128バイト固定長の規格。
1996年に採用された。

- TAG（3バイト）: タグの開始を示す識別子（文字列 "TAG" 固定）
- 曲名（30バイト）
- アーティスト名（30バイト）
- アルバム名（30バイト）
- 制作年（4バイト）: 西暦4桁
- コメント（30バイト）
- ジャンル（1バイト）: 定義されたジャンル番号（0〜255

ただし、書き込める情報の制限が多いため現在ではほとんど使われていない。
## ID3v2
サイズ制限を大幅に引き上げ、取り扱える情報量も大きく増えた。

ID3v2.2, ID3v2.3, ID3v2.4の3つがある。
