# ギャラリー珈琲店 古瀬戸
神保町にある喫茶店。さぼうるとか石釜bakebread茶房 TAM TAMの近く。

入ったら説明書きの看板があるからそのとおりにすれば良いのだが、
好きな席に座るとそのうち水を持ってきてくれてオーダーもその時に聞いてくれる。
会計は現金のみ後払い。

## 2026-09-11
ギャラリーで絵画が飾ってはあるのだが端っこの方に座ってしまってよく見れず...
歩いて見て回ったりするものなのだろうか...そんな人は居なかったが。

古瀬戸ブレンド 650円。

ミルクがついてきた。最初はブラックで飲みながら少しずつ足している。入れると少しマイルドになる。

コーヒーの味は普通かな。可も不可もないというか、家で飲むのとあまり変わらない。
そこまで違いが分からない人間なのか、コーヒーというよりは場を売っているというのか。
実際、会話をしながらという人も多い。居酒屋のアルコールなし版、この店に限らないのだけど...
