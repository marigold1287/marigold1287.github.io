# ずっとやりたかったことを、やりなさい 8週目の課題
喪失をチャンスに変える

失ったものに執着すると必ず行き詰まる。次に何が必要かを自問すること。

## 子どものときの条件づけ・エクササイズ
両親がアートをどのように考えていたかというのは私には分からない。
そういったことに関心のあるような家庭ではなかったように思う。

ただ、物心着く前から1000-2000ピースくらいのジグソーパズルが飾られていて、
星座のイラストが描かれたものだけは覚えているが、他にもいくつかあった。
その影響か、私もディズニーのジグソーパズルや名前は忘れたが
風景画のパズルを組み上げたことがあった。

創作活動とは違うかもしれないが、

- 学校に行きたくないという私の気持ちを否定されたこと
- そういうときにはPCを取り上げられそうになったこと
- いわゆるオタク系のアニメや漫画への興味を揶揄されたこと

こういったことは印象に残っているし自分の趣味や好みを隠そうとする性質に繋がっているように感じる。

アーティストとはどのような人物か: 個性を表現する手段を持っている人

もし自分が本当に才能があると思えるなら: プログラマーとして自立したい。本職はプログラマーですらないが。

### 新しい子ども時代を作ろう
幼い頃から狭く深くの交友関係で一度に1,2人の友達しかいなかった。
しかも、その友達に限って転校することが多くて、友達と呼べる人がいなくなったのは小学5年生のときだった。
当時の関係をもっと長く続けられていたらもう少し普通の人間でいられたかもしれないと思う反面、
こういった境遇を自分のアイデンティティとみなしてしまっている自分もいる。

この部分を新しく塗り替えたいという思いはそれほど強くないのかもしれない。

となると、大学の専攻を情報系にしてIT関係の仕事を本職にするというのも考えられる。
ただ、今の私は別の専門を専攻しつつプログラミングもやっているという二刀流のような状態で
だからこそ、他にない独自な経歴と言うか人間でいられると言うこともできるように感じている。

そうなると、子ども時代を塗り替えたいとは思っていないということになる。
それほど楽しい時期ではなかったが、今の自分を形作る要素として受け入れられているのだと思う。
