# リプレイゲイン
Loudnessというのは音声全体の平均的な「聴感」上の音量。
LUFS（Loudness Units Full Scale）は人間の耳の聴こえ方を考慮した音量の指標で、
標準的には-16や-18くらい、0に近いほど大きな音になる。

Peak: 音声波形の瞬間最大振幅。1.0(0.0dBFS)が上限。

Gain: 音量をどれだけ変化させるか（LUFSを-18にするためにどれだけ変化させるか。

Track: 曲ごとに変える。アルバムを混ぜてランダム再生する時はこっちを使う。

Album: Albumの平均音量をもとに音量を変える。1枚のAlbumの中にあえて音量の大きい曲と小さい曲が混ざっているような場合にはこっちを使うほうがそういった表現も再現できる。
