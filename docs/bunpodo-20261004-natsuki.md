# 文房堂 なつき個展『甘さひかえめ』
<https://x.com/bumpodo/status/2105121956710461519>

この方もまたデ・ジ・キャラットくらいな古き良き美少女イラストという画風が好き。

ポストカードを二枚お迎え、1枚は今回の個展のメインビジュアル、もう1枚は同時期に開催されていた
画材展のメインビジュアル。

席が空いていたからコーヒーを飲んでしばらくゆっくりしていた。
その間に額装が一つお迎えされていくのを目撃した。
