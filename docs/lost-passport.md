# パスポート再発行に必要な書類
## 必要な書類
### 紛失時
- 紛失一般旅券等届出書 申請書DLサイトから落とせる
- （現地の警察署にて）警察署の発行した紛失届出を立証する書類又は消防署等の発行した罹災証明書等
- 写真 縦45mm x 横35mm
- その他 本人確認できる書類
### 新たなパスポート申請時
- 一般旅券発給申請書 10年用または5年用
- 戸籍謄本全部事項証明書（原本）
- 写真 縦45mm x 横35mm
### 戸籍謄本全部事項証明書
- 足立区の場合 <https://www.city.adachi.tokyo.jp/koseki/kurashi/todokede/konbinikoufu.html>
- <https://www.lg-waps.go.jp/01-06.html>

本籍地以外の場所で取得したい場合は利用登録申請が必要。
上のサイトを参照。コンビニでできる。
