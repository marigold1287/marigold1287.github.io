# 2010年以降くらいのゲーム変遷
## 大学時代
2012年から2015年ごろ

- [hengband](./hengband.md)
- [TOME4](./tome4.md)

特にTOME4は会社に入ってからもかなりやっていて私が生涯で一番プレイしたゲームかもしれない。

研究室に入ってからはあまりゲームをやらなくなったように思う。
朝6時くらいに家を出て夜の11時とか12時くらいに帰ってくるみたいな生活をしていたり、
そこから崩れて色々とグチャグチャになってしまった時期もあった。

あとは[LoL](./league-of-legends.md)か。黎明期に。これもやる方は続かなかったが、
見る方は今になっても続いている。私が唯一追いかけているe-sportsだ。

ハクスラだとPoEとかdiablo2もプレイしていたかな。カードゲームだと[Hearthstone](./hearthstone.md)とか。

そういえばローグライトというかbinding of the isaacをめちゃくちゃプレイしていたな。
買ったのは2012年1月23日だ。
## 社会人になってから
TOME4も長期休みの時にプレイしていたのだが、
購入してハマったとなると[Factorio](./factorio.md)かな。
2020年末ごろからプレイしている。

ときおり美少女ゲーム、はぴねす2とか乙女ドメインとか永遠のアセリアとか...もプレイしていた。
ただ、最後までプレイしたのは乙女ドメインだけかも。永遠のアセリアは1週はしたけど...
はぴねす2はいまだに積んでいる。

そのあとsteamで[うたわれるもの](./utawarerumono.md)がリリースされているのを知ってようやく続編をプレイ。

ただ、この頃にアイカツ、ラブライブ、そこから派生して旅行や登山と趣味が変わってしまって
ゲームをやること自体がほとんどなくなってしまった。

アイカツ関係の同人誌を書いているポンケさんという方の影響で[MtGA](./magic-the-gathering-arena.md)を
やりはじめたこともある。ただ、デッキ構築や回し方が全然分からなくて挫折。
フレーバーテキストとか奥深そうな世界観は好きなのだけれども。


スマホゲームは一時期[プロセカ](./project-sekai.md)をやっていたけど、
結局、音楽が聴ければいいんだよなという感じ。
いつサービスが終わるかわからないものにお金をかけるというのがよくわからない。
まあ、一時期は課金もしていたのだけど。


## 最近（2026年10月16日）思うこと
misskeyでlolのworldsを見てるとノートしたのをきっかけに、ゲームについて振り返りたい気持ちになった。

美少女ゲーム、工場系シミュ、カードゲーム、硬派なローグライク、私にあっているのはどれだろうか。

カードゲームは全然プレイ経験がないから本当の初心者。
pay to winでないならやってもいいかな。というよりは、カードのフレーバーテキストとかが好き。
ストーリー的なものをひっくるめてハマれば面白そう。

工場系はプログラミングとか自動化が好きな身としては合っているとは思う。ただ、今さらゲームというのもなという気持ちが強い。

美少女ゲームは昔からなのだが、エンディングまでクリアできないことが多い。
受け身で話を聞くというのが苦手なのかもしれない。
漫画や本は比較的受け入れられるのだが、アニメもほとんど見れないのだ。
ただ見ているだけの時間が苦手だったり、他の作業をしてしまうから頭に残らない。
反面、映画は時折見に行くのだけれども。それは、映画を見る以外にできることがないからなのかもしれない。
