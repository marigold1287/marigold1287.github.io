# Alipay(支付宝)
各種支払い、地下鉄やバスの乗車用のQRコードも取得できる

デリバリー([淘宝闪购](./taobaoshangou.md))も利用できる。

## 支払い優先順位
パスポート番号と紐付いているからか、会社スマホと私用スマホの両方で
公共交通機関用のQRコードを取得できないため、
私用のスマホでQRコードを取得して会社のカードで支払いをしたい場合は
クレジットカードを二枚登録しておく必要がある。

登録は設定画面で普通にできて、通常の支払いなら都度カードを切り替えればどれを使うか選択できる。
公共交通機関の場合は優先順位が一番高いものが使われる模様。

設定画面、右上の歯車アイコンをタップするとPayment Priorityがあってこの順で使われる。
ただ、設定を忘れると私用外出の分が会社のカードで支払われるみたいな事故が起こりそうなので注意。
使うときだけ登録して、使わなくなったら削除しておいたほうが安全かもしれない。
