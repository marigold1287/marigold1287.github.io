# いつも寝落ちしてる
ここ何日か夕飯を食べる、歯を磨く、風呂に入る、それで椅子に座って少ししたら寝落ち、
深夜1時位に目を覚まして布団に入る。すると5時位に目を覚ます。

結局6,7時間は寝ていることになるから健康的といえば健康的なのだが...

活字断ちのことは、本や漫画を読まないということは継続できているが、
misskeyはやってるしニュースも見ている...
これでいいのか?

私にとってのアーティストというのは文章を書くかコードを書くかということになるのだけど、
どっちも一日中やっているとくたびれてしまう。

先の先を考えすぎているのかもしれない。仕事をする、金を稼ぐ、その先は?

旅行に行く、山に登る、その先は?

楽しいことを楽しいことと感じること、楽しいを目的にするというのができていないのだろう。
