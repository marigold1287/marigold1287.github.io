# emacsの補完機能改善
emacsを使い始めたのは研究室に配属されたときだから、もう10年以上使っていることになる。

<!-- more -->

その割には補完機能というのがよく分かっていなくてコーディングのときにはVSCodeを使うか、
力技でどうにかしているような状態だった。

とくにmarkdownで記事を書くためにファイル名補完をできるようにしたかったのだが、
色々調べているうちに `cape` を使うのが良さそうということを知った。

```elisp
(use-package cape
  :ensure t
  :bind ("C-c p" . cape-prefix-map)
  :init
  (add-to-list 'completion-at-point-functions #'cape-file))
```

これで `./ C-c c p` でファイルリストが表示されるようになる。
