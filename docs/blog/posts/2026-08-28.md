# マジカルミライに行ってきた
[マジカルミライ 昼公演](../../magicalmirai-2026.md)に行ってきた!

今回は推しとお出かけするためのグッズを手に入れようということで
ラバーキーホルダーと小さい雪ミクぬいをお迎えした。
山につれていくのだ!

-------------
中国研修の後任者はすでにわたしと同じ場所で活動していて毎週週報を送ってくるのだが、
文章の書き方の問題なのかもしれないが、長文で充実しているような印象を受けてしまう。
端から見るとこういうふうに映るものなのだろうか。

ほとんどの時間をデスクで特にやることもなく過ごすだけの社内失業状態に感じていた。
実はそれは私だけなのだろうか。こうなる可能性は予期していたが、
気落ちしてしまうというか、充実していますなどとなったらわたしの立場はどうなるのだろうか。
私が間違えていた?

とりあえず、会社スマホの電源を切ることにした。音信不通になるのはまずいかもしれないが。
こうやって自分で自分を悪い方に追い込むのはわたしの悪い癖だ。
