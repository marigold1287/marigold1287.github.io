# COMITIA157に行ってきた
この日の未明に関東地方で大きな地震があった。でも、わたしの家は思いの外揺れが小さかったように感じる。
頑丈なのか?私が鈍感なのか?

休職中にこんなところに行って良いのかという疑問は感じていたが、
仕事がどうとかいう以前に、自分の好きを取り戻したい、あるいは、見つけたいという方が正しいかもしれない。
そっちのほうがこれから生きる上でよっぽど重要だと思ったのだ。

その日の感動は[COMITIA157](../../comitia-157.md)にまとめた。
好きなイラストを見つけて集める、わたしはイラストを描くことはできないけど、
こういう形でイラストを通じてつながることもできると気づけただけでも行ってよかったなと思えた。

次回も必ず参加したいなと思う。

帰りは無印でポスカを保管するためのリフィルを購入、ちょうど良さそうなのがあってよかった。
リフィルA4ワイド用というのはかなり良さげ。大抵のポストカードが入る。
わたしの好きを集めた私だけのファイルをつくるのだ。


自分にできる創造的なことは何だろうと考えた時に
ミクやにゃんぷっぷー、しゅいろままと一緒に山に登って写真を撮るみたいなことをふと思いついた。
こういうのも一つの創造のあり方なのではないだろうか。どうだろう。
