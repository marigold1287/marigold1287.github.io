# おばけのおいしいひと休み
これが実話かどうかよくわからないと言うか調べていないが、
半年以上休職しているという言葉が出てきた。

私も今仕事に行っていないが、内省的になりつつも何かを生み出したい気持ち?のようなものはよく分かるような気がする。
このおばけは料理という創作に目覚めたわけで、それに比べると私はこうして文章を書くという形で
自分の存在を留めておこうとしている。

仕事をしているとどうしても仕事に関係のないこととか役に立たないことは置き去りにされてしまうことになりがちだが、
立ち止まっているからこそ見えてくるものというのは実際あると思う。

私もnoteに色々書いているように今までしてこなかったことに挑戦したり試したりする機会が増えたし、
それもひっくるめて考えれば休職というのは「良い経験」なのかもしれない。
もちろん、経験しなくて済むならしないほうが良いとも思うが。

それにしても、読めば読むほど私と同じようなことを考えている...。
休職するとみんなこうなるのか?あるいは作者さんと私の波長が合っているのか?
