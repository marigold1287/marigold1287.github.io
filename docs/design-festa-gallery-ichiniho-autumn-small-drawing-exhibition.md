# いちにほ 秋のちいさなドローイング展
- 訪問日: 2026年10月18日
- 場所: [デザフェスギャラリー原宿](./design-festa-gallery.md) EAST 203

Xで告知を見かけて興味を持ち訪問。

告知ではかなりの作品が展示されている様子だったが、
訪問したのが最終日だったこともあってか
作品もほとんど売り切れてしまっていて、作家さんがオーダードローイングをしていた。

名刺も切れてしまっているようでもらえなかったが、
ハロウィンということでペコちゃんのペロペロキャンディをもらった。

またの機会にと言って後にする。
