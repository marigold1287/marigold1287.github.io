# グラフデータベース
会社でナレッジベースを構築するのに参考になるかと思い購入した。

どの顧客がどの製品を使っているか、製品について説明している資料はどれか...など
グラフ化すると面白そうな要素は色々と思いつくのだが、
グラフデータベースを作る一番の目的は探索効率の高さという点にあるように思われた。
今の段階では人間が読めるナレッジベースを作るべきで、グラフデータベースはその次のステップの話だろう。

この本で身につけた知識が役に立つのはもうしばらく先のことになりそうだ。
