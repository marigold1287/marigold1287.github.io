# 初音ミクとEko iXimaのミクストメディア展
2026年8月25日訪問。

なぜか良く分からないが外国人割合が非常に高かった。さすがミクちゃん。

展示物の写真撮影はOK、ただし動画はNG。

予約は必要だが、入場は無料。もうね、本当に良かった。
イラストが額装されているのだけれども、それがただのイラストでなくて奥行きがあって
今まで見たことのない斬新な展示だった。

パネルを使ってイラストを3次元に再構成している作品もあって
こう2次元と3次元をつなぐというか、そんなコンセプトの展示会だった。
