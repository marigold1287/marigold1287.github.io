# Spring Japan 国際線
## チェックイン
<https://jp.ch.com/flights/new-c-airport-traffic-1/>

自動チェックインはない。窓口で手続きする。搭乗手続きは150分前から可能。
時間になったらフロアにアナウンスが流れる。

## 手荷物重量
搭乗手続きカウンターの入口に秤がおいてあってそこに乗せる。

搭乗口前にも秤が置いてあったが確認されることはなかった。
### ノートパソコンは重量制限に含まれない
<https://jp.ch.com/help/int/IJ/baggage-inflight>

自己申告した上で取り出して測ればその分を除いてくれそうではある。

搭乗手続き時に荷物を預け入れ、航空券をもらう。
パスポート番号と航空券の情報が紐付けられているからか、旅程表を見せる必要はなかった。
