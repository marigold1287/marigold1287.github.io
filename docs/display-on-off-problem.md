# PCがスタンバイ状態なのにディスプレイがON/OFFを繰り返す問題と対処法
備忘録。

PCがDELLのディスプレイを使っているPCでPC側をスタンバイ状態にした後、
モニタに「デバイスからのDP信号がありません」「スタンバイモードに入ります」と表示されて
その後しばらくするとまた「DP信号がありません」と表示されてディスプレイが起動とスタンバイモードへの
移行を繰り返してしまう問題。

ディスプレイに付属しているスピーカーが原因だったようで、ディスプレイ側のオーディオをOFFにしたら直った。
わたしの場合はディスプレイのスピーカーを使っていないからこれで解決した。

特に夜寝る時にモニタが付いたり消えたりして非常に鬱陶しくて困っていたのだが、ようやく解決できてうれしい。

と思って、この日の夜に寝ようとしたら解決していなかった...

問題自体は

```bash
echo s2idle | sudo tee /sys/power/mem_sleep
```

で解決する。ただ、これをやると本体側のLEDが点きっぱなしになってしまう。
ubuntuのスタンバイモードはいくつかあって

```bash
echo deep | sudo tee /sys/power/mem_sleep
```

でdeepモードになるのだが、deepだと信号が消失するのだろう。
s2idleはそのあたりの信号が残ったままなのか、本体側の電力消費が多くなりそうな気がする。

まあ、モニタの電源を切れば良いのだが。
