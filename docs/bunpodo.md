# 文房堂
わたしが[イラストを描く](./creative-things-i-want-to-do.md)ために鉛筆とクロッキー帳を買ったところ。

3階がギャラリーカフェ、4階がギャラリーになっている。

3階までは階段で上がれるが、4階より先はエレベーターのみか。


## ギャラリーカフェ
3階にあるカフェ。ギャラリーも併設されていて壁際に作品が飾られている。
特に何も注文せずに鑑賞だけでも可。

WiFiあり。
席に座るとメニューを持ってきてくれる。
後払い、というか注文の品を運んできた時に伝票を渡されるタイプの店。

クレカ等も使用可能。
