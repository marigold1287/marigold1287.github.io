# 安達としまむら
学生同士の百合作品。原作はライトノベルだが、漫画化もしているしアニメ化もしている。

常に確認していないと不安で耐えられないといった様子の安達がわたしにそっくりだ。
もっと言うと、一見明るく振る舞っている割には裏でなんとも哲学的なことを考えているしまむらにも感情移入できるところがあったりして、とにかくすっごくいい百合作品だからぜひ読むべき。
漫画もいいが、やっぱりラノベがおすすめ。
