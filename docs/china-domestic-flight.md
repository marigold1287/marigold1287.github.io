# 中国国内線
空港に着いたら、航空会社ごとの受付窓口が表示されているから窓口のアルファベットを確認する。
中国語が基本だが大抵の係員は最低限の英語を話せそうな感じ。日本語はアプリを使わないと無理そう。
ただ、そもそも何語を話しているのかがよく分からなかったりするから事前に聞かれる内容を把握しておいたほうが良い。

1. パスポートを見せる。
2. 預け入れ荷物（Checked baggage）、機内持ち込み（carry-on baggage）かは聞かれると言うか荷物を置けば良さそう。
3. 預け入れ荷物をコンベアの上に置く。横にしてタイヤを自分の側に来るようにする、写真が貼ってある。
4. 通路側か窓側か聞かれる。过道侧，窗边（Guòdào cè, chuāng biān）。
   aisle（アイル） side, window side。
5. 荷物にバッテリーは入っていないか。

不安ならNo battery, Aisle sideなどと書いたメモを用意しておいて見せたほうが確実。
