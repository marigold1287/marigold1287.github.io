# Chaina Unicom
<https://www.cuniq.jp/detail-info>

## シーズンSIM
<https://www.cuniq.jp/use-flow>

1. 届いたQRコードをスキャンし、プロファイルを端末にダウンロードしてください
2. スキャンした後、ご使用の端末に表示された指示に従い、設定を行ってください
3. APNが3gnetに設定されていることを確認してください
4. 中国本土、中国マカオ、日本のいずれかの地域でローミングを有効にしてください
5. VoLTEが有効になっているか

## APN設定
これをやらないとつながらないので注意。

アクセスポイントの編集
- 名前 China unicom（適当でOK）
- APN 3gnet
- APNタイプ default,supl と入れる。

ほかはそのままでOK。画面右上「...」をタップ、保存する。
