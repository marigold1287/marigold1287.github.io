# WFP日本人職員活動報告回
- 訪問日 2026年11月15日
- 訪問場所 東京スクエアガーデン6F シティラボ東京
## メモ
ウクライナ、バングラデシュ、ジンバブエでの活動についての紹介。

「誰一人取り残さない」をスローガンに支援を行っている。SDGsと同じかな。

120万人のロヒンギャ難民の保護。資金不足により家庭の状況に応じて3段階に分けて支援のレベルを調整している。

難民キャンプでの生活が長期化している場合、そのキャンプで産まれる子供というのがでてくる。
そういった子には国籍がないことも多いそうだ。

コックス・バザールからベンガル湾の無人島まで10万人を移送する計画が実行された。
その時、子どもたちは初めての遠出?ではしゃいでいる様子だったという話を聞いて
子供の無邪気さというか、何でも遊びに変える力強さのようなものを感じた。

職員の方々としても、食料を渡すというのは何かを始めるための基盤づくりであって、
対症療法でない、より本質的な対策が重要ということは自覚しているようだった。
WFPの資金に十分な余裕があったら、気候変動対策にその資金を当てたいと話している方もいた。

--------------------------------

どれくらいがサクラでどれくらいが本当の支援者だったのだろう。ボランティアも混じっていたのかもしれない。運営のチャットがスクリーンに映ってしまったりしていて、その内容がちょっと昭和感みたいのを感じるところがあった。こういった取り組みは今回が初めてだったそうで、運営側も慣れていないのだろう。

まあ、それはよいとしても、私自身が支援に携わるというのは無理だなと思う。そうなると、自分の持っているスキルで金を稼いで支援に回すのか。ずっとそうしていたわけだけど。

「誰一人取り残さない」という言葉を私も忘れないようにしたい。

最後に記念撮影をした。写真が送られてくるらしいけど、いるのか？

後日、メールで送られてきたけど見ないで捨ててしまった。

メモ紙に使っていた付箋はメッセージボードに貼り付けるためのものだったらしい。。。
