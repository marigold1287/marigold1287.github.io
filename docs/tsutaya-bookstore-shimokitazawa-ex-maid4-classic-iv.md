# グループ展「ClassicⅣ」
- 訪問日: 2026年11月11日
- 訪問場所: [TSUTAYA BOOKSTORE 下北沢](./tsutaya-bookstore-shimokitazawa.md)

3階の小さなスペースで開催されていたメイド展。

参加している作家さんたちが豪華すぎる...。

会場には誰もいない、と思ったら
小さいテーブルと椅子が置いてあって、そこに店員なのか絵師さんなのか何だかよく分からない人が座っていた。
誰だったのだろう。写真を撮りたかったのだが撮りそこねてしまった。

同人誌やグッズも色々置いてあったが、ポストカードを3枚お迎えする。
