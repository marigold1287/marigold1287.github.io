# 淘宝闪购
Táobǎo shǎn gòu

[Alipay](./alipay.md)のミニプログラムから起動できるデリバリーアプリ。

## 事前準備
プログラムを立ち上げたら我的で住所を登録しておく。
部屋番号まで入れておく。
## 注文
食べたいものを選べばいいからここは難しくないはず。
初回は50%OFFくらいで頼める。

配送費は8元くらい。包装費が3元くらい。

時間を指定することもできる。お金を払えばお急ぎ便みたいなのも使える。
## 配達
配達員によるかもしれないが、電話がかかってくる。
上海のマンションであれば電話に出なくても部屋前まで持ってきてくれる。
ノックされるから出ると手渡ししてくれた。
