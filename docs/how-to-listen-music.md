# 音楽の聴き方を考える
昔の昔?2005年とかそれくらいの時期はアニソン垂れ流しみたいなネットラジオがたくさんあってそこで聞いていたり、アングラなサイトでmp3を落としたりして聞いていた。

ただ、2010年にダウンロード違法化という法律が話題になって、ダウンロードして聴くというやり方はこれを機に止めにした。

ネトラジは時代の流れなのか、そのへんが厳しく取り締まられるようになったのか、いつの間にやら見かけなくなったな。

それからは当時のMP3を聴き続けていたり、youtubeで良さそうな曲を見つけては聞いていたり、これまた合法性が良く分からないがレンタルしたCDをリッピングしてコレクションを増やして聞いていた。

レコチョクでmp3を購入することも時々あった。楽天のシステムで決済できるのが便利だったのと、当時は自分でファイルを保有しておきたいという欲も強かったのだ。

ただ、2023年の末くらいかな。ボカロ曲を聴くようになってからはこのやり方が難しくなってくる。たいてい、ニコ動やyoutubeにUPされているだけで曲ごとに購入できるという場合がほとんどないのだ。

もちろん、yt-dlpとかを使って音源だけ引き抜く手法もあるにはあるのだが、これも合法性とかを考えるとできるけどやっていいのか?という罪悪感を伴うからやり方は覚えたけど定着することはなかった。

そういうなかでyoutubeやspotifyみたいなストリーミング配信に興味を持つようになる。youtube musicが筆頭だったのだが、課金しないとバックグラウンド再生ができない。spotifyは広告こそ入るが無料でもバックグラウンド再生ができるというのが決め手になってspotifyを使ってみることにした。これが2025年7月くらいのお話。

それで、今日までspotifyに課金し続けてきたのだが、
最近になってどうせ課金するならyoutube musicのほうが良いのではと思いはじめる。
古いゲームの曲はspotifyに収録されていないことも多いし、むしろこっちのほうが良いように感じる。

## Lofi系
作業用には声の入っていないBGMをよく聞いていた。

特にLofi Girls、2023年7月29日の日記に

> とりあえずyoutubeは見ないでいられた。ゆっくり動画とか、無意味なものばかり見ていただけに、これは意味のある進歩だろうと思う。その代わりにLofi girlというチャンネルをBGM代わりに流している。あまり好きな絵柄じゃないなと倦厭していたけどしばらくみていると好きになってくる。

と書いてあった。ゆっくり解説動画みたいのをよく見ていたから、その代わりといったところだろう。

> 今日は集中して本を読めていた。それに、ようやくyoutubeで動画を見る時間を減らすこともできている。lofi girlsのおかげ！

とも書いてある。

2026年10月、休職中にOSMやwikimediaみたいなコモンズ的な考えというかサービスに魅力を感じるようになって（そのことはまた別の機会に書くとして...）、BGMについてもそういう要素を取り入れられないかと考えるようになった。

そんな話をclaudeとしていたらsomaFMという広告なし、寄附金運営のネットラジオを教えてもらった。これがジャンルも色々あって好みのチャンネルを見つけやすいし、lofi girlsみたいにyoutubeを介さないで.plsから直接再生できるからメモリ使用量も少ないのも非常に良い。
最近はmpg123というのを使って再生している。

```bash
mpg123 --title -@ https://somafm.com/groovesalad.pls
```

[COMITIA](./comitia-157.md)に参加したことでクリエイターさんとの距離感というか、応援の仕方を考えたいというのも理由の一つだ。

[魔女の工房展/The Tarot展](./gallery-artist-guild-20261002.md)での雑談中に
M3というCOMITIAの音楽版みたいなイベントを知って、misskeyで海風夕さんという
カフェ系?のBGMを作っている方を発掘した。

この方、もちろん、youtubeやspotifyにもあるし、M3に行けば直接買うこともできるだろうし、BOOTHでCDやDLカードも販売している。それにBandCampというサイトでも配信していたりとまあとにかくあらゆる方法で配信しているのだ。

BandCampも触ってみた感じ結構良さそう。ただ、日本人は少なめ、かな。見つけ方が課題になりそう。

クリエイターさんからするとどの聴き方で聴くのが一番嬉しいのだろうか。というのを疑問に感じる。

最近は外でsomaFMを聴いていても結構いい感じ?に思えてきていて、そうなると
サブスク系の契約が必要になるのかということも疑問になってくる。

外はSomaFMとMP3、家はYouTubeみたいな使い分け、あるいは音声ありの曲をもっと
集中して聴くとか。リズム感だけで好みを判別しているようなところがあって、
好きだけど歌詞とか内容がわからないみたいな曲がたくさんあるのだ。
これは一番最初に聴いた曲がQueenとかBilly Joel（母が聴いていた）みたいな洋楽だったことも影響しているのかもしれない。

## おまけ ボカロを聴くようになった経緯
2023年末、バンドリでカバー曲を聞いているうちに原曲を聞きたくなって
今更ながらハマってしまう。はじめのころは「かいりきベア」さんとかをよく聞いていたかな。

2021年にアイカツ、そこからプリキュアやプリマジなどの女児向けアニメ、
2023年はじめ頃にラブライブと色々渡り歩いてきたが、最終的には
今日の時点でもボカロメイン（プロセカも聞いている）に落ち着いている。

やっぱり、創り手が見えるというか近いというのが大きいのかもしれない。
あとは商業的すぎない（気がする）という点も魅力。

ラブライブではついに行かないままになってしまったが、
ライブ([マジカルミライ](./magicalmirai-2024.md))にも初めて参加した。

発祥の地もわたしと同じ札幌だしその辺も含めて好き。

あとはこれまでの作品では推しが分散してしまって宜しくなかったが、
ボカロに関してはミクを最推しにしていられるというのも良い。
もちろん、ルカさんやMEIKOも好きではあるが...

ラブライブにハマっていた時期もスマホゲームに手を出すことはなかったが、
プロセカしばらくプレイしていた。ただ、しばらくプレイしていて、
結局やりたいのは音楽を聴くことであってゲームじゃない、
スマホゲームに課金するのももったいないといろいろ思うようになって止めてしまった。

当時のメモに以下のことが書いてあった。

-------------

始めたきっかけは2024-06-01、一時期嵌っていたVtuber音彩さんの影響を受けて
手を出したこと。音ゲーという馴染みのジャンルではじめのうちはあまり楽しさも
分からなかったのだが、キャラの魅力とかストーリー、というかニーゴが好きで
嵌っていたのかなと思う。

仕組みが分かってきてからはスタミナ（ライフボーナス）消化のために
朝夜プレイするのが日課になってきてだいたい1時間位プレイしていただろうか。

で、今は5周年イベントのまっただ中なのだが、義務感というか
消化のために惰性？強迫？でやってるだけだなというということに気づき始める。
それだけじゃなくてちょうど寄付についていろいろ考えていた時期でもあって、
アプリに毎月課金するのもどうなのだろうという気持ちも強くなってきていた。
クリスタルは買っていないが、ミッションパスに毎月2000円使っていたのだ。

もともと始めるきっかけにもなった楽曲はspotifyでもyoutubeでも聞けるし、
ストーリーもイベント終了後にyoutubeで見れる。
ゲームをプレイできなくなるというのはあるといえばあるのだが、
でも、フルコン目指すための作業とかしてる面も強くなってきていたし。
何より1日1時間をこのゲームに費やす必要もないだろうという気持ちが強くなってきたのだ。

そんなことをGeminiと会話していて、ほとんど何のためらいもなくアプリをアンインストールしてしまった。
十分楽しめたし、今まで触れてこなかった世界に触れられたというのもあるし、これでいいだろう。

興味深い。各ストリーミングサービスがクリエイターに支払っている金額が例示されている。

プロラタ方式

1. 月額料金や広告収入をすべて1つのプールに集める
2. プラットフォーム全体の総再生数を数える
3. 各アーティストの再生数が総再生数の何%かを計算する
4. プールからその割合分を、各アーティストに分配する

となると、私が再生したからといって、その再生がそのままアーティストに分配されるわけではないのか。
