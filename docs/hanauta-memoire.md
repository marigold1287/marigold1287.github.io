# 花唄メモワール
花山温泉という温泉宿が舞台の百合漫画。
実際は福島県会津若松市にある東山温泉がモデルだそう。

タイムスリップもので大正時代と令和を行ったり来たり、
大正時代にはほとんど知られていない知識を持ち込んで事件を解決したり、
それによって令和の時代に少しの変化が起こっていたり...


[ろうそく祭り](https://www.aizukanko.com/kk/festival/erousoku-matsuri)というのが
取り上げられていて、聖地巡礼に良いかなと。
