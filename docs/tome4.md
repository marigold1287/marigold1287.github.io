# TOME4
いつから始めたかは定かでないが、会員登録してから13年くらいと言うことだから大学生の時だろう。変愚蛮怒をやっていたころと符合する。

このゲームは私が生涯で一番プレイしたゲームだろう。おそらく。これか[変愚蛮怒](./hengband.md)のどちらかだけど、ゲームに対する理解度はtome4の方が深かったかな。

いわゆる不思議なダンジョン系はあまり合わないのだよな。買値と売値を覚えるとかそういうのが面倒なのだと思う。まあ、ローグライクもそういう節はあるが、でも、アイテムにエゴがついたりしてハクスラ要素もあるのがいいのかもしれない。固定アーティファクトとランダムアーティファクトがあって。
