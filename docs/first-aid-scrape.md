# 擦り傷の対処法
この日にジョギング中に転んでしまって擦り傷、出血してしまった。

こういうことはいつでも起こりうるし、
登山中にも起こるかもしれないから処置の仕方や道具を調べておいたほうが良いかもしれないと感じ
少し整理。

特にわたしの場合、絆創膏をべたりと貼ると剥がす時に苦労するからガーゼのほうが良いかもしれない。

1. 水で洗う
2. 非固着性ガーゼを当てる
3. 医療用テープで固定する。
4. 必要なら普通のガーゼを重ねる
5. 服に触れる場所はガーゼを大きめにする

体液が出てこなくなってきたら開放しても大丈夫。

過度に消毒したりするのは却って良くないらしい。
浸出液には皮膚を修復するための成分が含まれているからある程度の湿度を保った状態で傷口を保護する。

- ガーゼ
- 医療用テープ
- 絆創膏
- それを捨てるためのゴミ袋
- これらを入れるための小さめの袋。防水性があると良い。
