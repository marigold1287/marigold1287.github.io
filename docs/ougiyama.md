# 扇山
秀麗富嶽十二景 6番山頂。1138m。

私が一番好きな山。

2026年1月に山火事になって全国ニュースになっていた。

火災後の印象は

- 梨の木平からの道は比較的安全、ただ、雨のあとは増水していて歩きにくい。
- 東側は倒木が多かったり治山工事の影響でちょっとした川ができてしまったりしていてやや歩きにくくなってしまった。
