# さめない街の喫茶店
ちょっと不思議な喫茶店キャトルに迷い込んでしまった女の子（すずめ）と
お客さんとの話。


## 雑感
現実世界でなにか大事なことがあったような気がすると思いながらも
夢の世界で暮らし続けるすずめに少し共感を覚える。

辛いことや苦しいことから逃れようとしているときに
こんなゆったりした場に身を置くことができたら...
そうして、もともと持っていた料理の才を活かして生活することができたら...

こういう生活がうらやましいな。
