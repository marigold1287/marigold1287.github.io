# バレットジャーナル
emacsを使っている私はタスク管理やトラッキング、デイリーログをorg-modeやorg-journalで、
外出先ではgoogle keepを使ってメモを取っている。スケジュールもorg-modeで管理していて、
形は違えど本書と似たようなところに行き着いているなという印象を受けた。

今のやり方はGTDの影響を受けてそれを自分なりにアレンジしたものになっている。
とりあえずInboxになんでも投げ入れて、いつやるかを決めて、というような感じだ。

一番の気づきはタスクとゴールを区別するべきという点だろうか。

今のやり方でもやるべきことの管理はできるが、人生全体を考えた時に
それらのタスクが何とつながってくるかという視点を持つことの重要性だ。

私の場合を整理すると大きな目標は以下のような感じになる。

こういったことを踏まえて今日なにをするか、今月なにをするかというのを決めていく。
定期的な振り返りというのもできていなかったから、夜、月末に振り返りの時間を取るようにしたい。

本書の中で「モーニングページ」というバレットではなく長文を書くメソッドが紹介されていたが、
私は今まさに『ずっとやりたかったことを、やりなさい。』を読んで実践しているところだ。
思ったことを何でも書くというのはこういった感想文を書く上でも非常に役に立っていると思う。
