# ベッドシーツ問題
フラットシーツは良いぞ!
## 敷ふとんカバー
ファスナーがついていてそこから布団を入れて使う。

入れるときは大変だがズレにくい。

ファスナー式とかゴム式?とか色々買って試してみたが、
私の部屋は狭苦しいから敷き布団カバーに入れようとすると結構大変でめちゃくちゃストレスがたまる。

### 敷布団カバー(全周)
[ベージュ シングル (105×210cm) テイジン 防ダニ(ダニ通過率0%)花粉カット 薬剤不使用 ノンダスト 37610105](https://item.rakuten.co.jp/texet/127/)

2022-07-01に購入。ホコリがひどいと言うので打ち込みの多いシーツを買ったのだった。
効果は良く分からない。これはすっぽり覆うタイプで短辺側にだけファスナーが付いている。
ダニ防止のためなのだが、入れるのにめちゃくちゃ苦労する。

## フラットシーツ
1枚の布でマットレスにも敷ふとんにも使える。
4隅を折りたたんで使う。

洗ってもすぐ乾く反面、毎回四隅を畳まないといけないのが手間、らしい。

2026-08-06、注文してみる。

2026-08-09。これだ！さっと掛けてさっと外して洗濯をして...いままで取り付け取り外しが面倒で
洗うのも億劫になっていたが、これならかんたんに洗えそう。
