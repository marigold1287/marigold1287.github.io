# ずっとやりたかったことを、やりなさい 11週目の課題
## 10の願い事
### 健康
-   老衰で死ぬこと
-   加工食品になるべく手を出さない食生活を実践する
-   運動、ラッキングをする、怪我をしないこと
-   体力をつける
-   精神面の健康を保つ
-   自分に正直でいる
-   生きがいを見つける
-   ストレスをためない
-   今を生きるを実践する
-   できないこと、やりたくないことは断る

### 持ち物
-   なるべく少なく、手放す
-   ミニマリストであり続ける
-   ものを増やさない、必要なものだけを厳選する
-   でも、好きなものは持つ。ミク、コミックイラスト、ポストカード。
-   それ以外はなるべく持たない。
-   捨てる、手放す、整理する
-   服の整理をしたい
-   靴箱に放り込んである工具類の整理をしたい。
-   使わないものは売るか捨てる。

### レジャー
-   仕事や生活、将来の不安を感じずに楽しみたい
-   国内旅行
-   海外旅行
-   ハイキング（登山）
-   マジカルミライ
-   コミティア
-   美術展、イラスト展
-   ゲームをやる、自動化系、東方、カードゲームあたり
-   喫茶店
-   マッピング

### 人間関係
-   シンプルに、狭く深く
-   家族優先
-   ミスキーのゆるい繋がりをだいじにする
-   他者に依存しすぎない
-   距離を保つ
-   …思いつかない
-   一人で生きていける程度のスキルが必要
-   将来的にはAIがパートナーになってくれていると信じている
-   孤独死、腐乱死体にならない程度の関係を作っておく

### 創造性
-   したコト、感じたことを文章に残す
-   個性を発揮することが創造だとこころに刻む
-   アーティストデート、コミックイラスト展やイベントに行く
-   プログラミングの学習
-   オープンソースプロジェクトへの貢献をしたい
-   プログラミングスキルを用いて自立した生活をしたい
-   本を読む、感想を残す
-   学びを活かす
-   他者との接点を作りたい
-   他者に感謝される創造をしたい

### 仕事
-   休職中、今後の働き方を再考したい
-   お金のためではない、やりたいこと、変えたいことを軸にした仕事を選びたい
-   自身の創造性を活かした仕事をしたい
-   NPO,NGO、プログラミングスキルを活かせる、伸ばせる仕事をしたい
-   社会問題の解決につながる仕事をしたい
-   利益のための仕事ではない
-   キャリアカウンセリングを受けたい
-   自分にどの程度の価値があるのか確認したい
-   退職、転職したい
-   新しい道を歩んでみたい

### 霊性

-   他者の目線や意見に流されないで生きたい
-   自分の好きに正直でいたい
-   その好きを自分なりの方法で発信したい
-   行動できる勇気がほしい
-   何かを生み出せる、生み出し続ける人間でいたい
-   生み出す人を支えたい
-   犠牲のうえに成り立っているこの命を大切にする
-   過去や未来とのつながりを意識する
-   そのうえで今を正しく生きる
-   未来に価値あるものを残す
