# 中国入国審査
電子申請しないなら到着後の入国検査場で記入する。

<https://s.nia.gov.cn/ArrivalCardFillingPC/entry-registation-home>

で事前申請できる。QRコードが表示されるが、係員に提示する必要はない。
画像は100kb以内と厳しいので事前に圧縮等してサイズを調整しておくこと。

招聘状の内容や中国での住所を入れておくこと。
招聘状の提出を求められるかもしれないから出せるようにしておくこと。

## 手順
1. パスポートを渡す
2. 指紋を採取する

それ以上のことは何も聞かれなかった。
無言でパスポートを返されて終わり。

QRコードを見せることもなかった。
パスポート番号で紐付けられているのかもしれない。
